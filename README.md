# Recipe Help: 

**Recipe Help** is a recipe recommendation system that enables users to explore recipes that fit their needs.

Currently, **Recipe Help** is only accessible locally via a CLI app. It may utilize a local model via [Ollama](https://ollama.com/) that assists in making recommendations.

### Dataset Attribution
This project uses the [recipes-with-nutrition](https://huggingface.co/datasets/datahiveai/recipes-with-nutrition) dataset provided by [DataHive AI](https://huggingface.co/datahiveai) under the terms of the [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.en) license.

* **Modifications:** Data is ingested into a database environment. During this process, some values may be normalized or excluded where appropriate.
